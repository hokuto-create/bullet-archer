# BULLET ARCHER 〜弾幕の射手〜

止まると自動で最寄りの敵を攻撃する、アーチャー伝説2風の 3D 弾幕サバイバルゲーム。
Three.js による単一 HTML ファイル構成で、ビルド不要でそのまま動きます。

## 遊ぶ

**GitHub Pages URL**: (公開後にここへ記入 → `https://hokuto-create.github.io/bullet-archer/`)

> GitHub Pages の有効化: リポジトリの Settings → Pages → Branch を `main` / `(root)` に設定

## 操作方法

| 操作 | PC | スマホ |
|------|----|--------|
| 移動 | WASD / 矢印キー | 画面タッチで仮想ジョイスティック |
| 攻撃 | 立ち止まると最寄りの敵へ自動攻撃 | 同じ |

- **止まって撃つ・動いてかわす**が基本。移動中は攻撃できません
- 敵は3種類: 突進してくる **chaser**、距離を取って狙撃する **shooter**、5ウェーブごとの **boss**
- ボスは足元に**赤いリング(予兆)**が広がったあと全方位弾幕を放ちます
- ウェーブをクリアすると **HP が 15 回復**

## ローカルで確認

`index.html` をブラウザで開くだけです(Three.js は CDN から読み込むためネット接続が必要)。

```bash
open index.html   # または ダブルクリック
```

- `docs/prototype/` — プロトタイプ参照用
