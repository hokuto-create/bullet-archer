# プロトタイプ置き場

もともとリポジトリ直下にあった React + Three.js のプロトタイプ `arena3d.jsx` をここに移動して参照用として残す予定でしたが、**リポジトリのどのブランチ・コミットにも `arena3d.jsx` は存在しませんでした**(初期コミットは README.md のみ)。

そのため、現在の `index.html` はプロトタイプの仕様(アーチャー伝説2風の操作、敵3種、赤リング予兆→全方位弾幕、ウェーブクリアで HP15 回復、仮想ジョイスティック + WASD)をもとに直接実装したものです。

手元に `arena3d.jsx` が残っている場合は、このディレクトリに置いてコミットしてください。
